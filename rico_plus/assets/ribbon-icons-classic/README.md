# Rico Icons Classic

This package contains **106 command icons**. Every command has light-UI and dark-UI variants as editable 64×64 SVG source and pre-rendered 64×64 PNG runtime assets.

## Cohesion redesign

The established icon set is retained unchanged. The 30 later-added commands were redrawn as coherent command families: application/view layout, tables, links, save/workspace actions, icon-family selection, and theme selection.

The redesign uses shared semantic primitives so related commands inherit the same base geometry and differ primarily by their action/state modifier.
