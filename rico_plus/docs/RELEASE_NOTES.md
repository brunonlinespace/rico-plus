# Rico Plus 0.0.2

Rico Plus 0.0.2 is a focused usability revision.

- Symbol is now disabled with the other document-mutating controls while Lock Editor is active.
- Keyboard Shortcuts is grouped by the top-level AppMenu menus and labels its filter **Menu:** while retaining **All**.
- The running application advertises the Suite Pythoine managed desktop identity convention so Plasma can identify the active window as **Rico Plus** rather than the Python interpreter.
